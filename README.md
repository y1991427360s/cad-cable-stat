# 电缆长度自动统计工具

本工具用于根据 CAD 导出的柜子坐标、固定走线路径和电缆竖井信息，自动计算 `自动统计.xlsx` 中每条电缆的路径长度，并生成可视化页面帮助复核路径。

## 工具 + 项目结构

本文件夹是**通用工具**，不放任何项目数据。每个工程项目一个独立文件夹，清册、CAD 数据、结果都在项目文件夹里：

```text
本文件夹（通用工具）
├─ calculate_cable_lengths.py / run_auto_stat.py   计算脚本
├─ cable_stat/                                    模块化计算引擎与可视化模板
├─ cable_stat_app.py / cable_stat_gui.py           桌面入口与图形工作台
├─ build_exe.ps1                                  测试、打包、验收和发布
├─ cad_cable_wizard.lsp                            CAD分步引导向导（推荐）
├─ cad_export_cable_route.lsp                      CAD仅导出命令
├─ 新建项目.cmd                                     双击创建新项目文件夹
├─ 项目模板\                                        新项目的骨架（也可直接复制改名）
└─ 项目\
   └─ <项目名>\                                     一个项目 = 一个文件夹
      ├─ 自动统计.xlsx                              清册
      ├─ data\                                      CAD导出数据 + 参数 + 别名
      ├─ outputs\                                   结果全在这里
      └─ 一键启动.cmd                               双击运行本项目
```

## 快速运行

### CAD 文字快速校核（HDDL）

在 CAD 中加载 `E:\366256\2027-AutoCAD-lisp\AA整合版本.lsp`，选中准备交给 `YSDL` 的文字后输入 `HDDL`。`HDDL` 已经完全内置在这个整合文件中，不依赖外部 LSP 或其他平台函数。命令按 YSDL 的行分组规则读取第二列电缆编号：同编号且起终点互换的合法镜像行不会误报；同向重复、超过两行或镜像两端原理号数量不一致时，整行改为红色并在行首生成 `[编号重复]` 或 `[原理号不一致]`。同一行第 5 列起的原理号/芯线号出现重复时生成 `[原理号重复]`。这样无需先导出 CSV、复制到项目或打开网页即可在原图上定位结构性错误。修正文字后重新选择并执行 HDDL，未被标记的行保持原有颜色。

行首标记统一放在 `HDDL_MARK` 图层；再次执行命令时只清理该专用图层中的旧标记，不会删除用户其他文字。

**双击 `电缆统计.exe` 就是完整软件**（图形界面，不需要装 Python）：

1. 点「新建工程」选择位置、输入名称，或用「打开工程」及左侧最近工程列表进入已有工程；
2. 把清册 Excel 放进工程文件夹；点「导出 CAD 向导」，在 CAD 加载后运行 `DDFD_CABLE_WIZARD`，把 CSV 导入工程 `data\`；
3. 在「工程概览」检查文件状态，在「计算参数」编辑并保存本工程的参数；
4. 在「柜名匹配」选择未匹配的清册柜名及对应 CAD 柜名，点「加入映射」后「保存映射」。相似名称只作建议，需要人工核对；
5. 点「开始计算」，查看阶段进度、耗时、长度汇总和带颜色的日志；在「问题清单」按错误、警告、提示筛选，选中一条可读完整说明；
6. 用「结果工作簿」「路径可视化」打开工程 `outputs\` 中的结果。CAD 重新导出后，按 `F5` 刷新再计算。

工作台支持 Windows 高 DPI；`Ctrl+O` 打开工程、`Ctrl+Enter` 开始计算。切换工程、刷新、计算或退出前会处理未保存的参数与映射；任务运行时可选择完成后自动关闭，文件写入完成后再退出。

每个项目文件夹里还有一个 `一键启动.cmd`：双击它会打开软件并**自动对这个项目开算**，习惯二选一。

exe 内嵌了计算引擎、项目模板和完整向导插件 `cad_cable_wizard.lsp`；根目录的 `cad_export_cable_route.lsp` 是仅供开发兼容的精简导出版，用户无需导出或加载。`.py` 源码留作开发和排查用（源码方式需要 `python -m pip install openpyxl`）。

当前版本为 **2026.09.26**。源码方式运行工作台：

```powershell
python .\cable_stat_app.py
```

修改 Python、LISP 或项目模板后，用已安装的 **Python 3.14、openpyxl 和 PyInstaller** 重新构建；脚本不会安装或升级依赖：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_exe.ps1
# 指定已安装的 Python：
.\build_exe.ps1 -Python "C:\Python314\python.exe"
```

构建会依次执行语法检查、`python -m test_calculate_cable_lengths`、`python -m unittest discover -v`，再把单文件无控制台程序生成到 `_build_release\dist\电缆统计.exe`。exe 内嵌图标、完整 CAD 向导、项目模板和 `cable_stat\visualizer.html`。

发布前，脚本自动生成独立的 `_build_release\smoke_<时间>\` 工程，用 `CABLE_STAT_SMOKETEST=1` 启动暂存 exe，核验两条合成电缆的直线/拐弯长度、别名、Excel/CSV/HTML/JSON 输出、内嵌资源，以及原清册未被改写。全部通过后，旧版复制到 `_build_release\backups\`，再替换根目录 `电缆统计.exe`；构建或验收失败会保留原发布版和诊断文件。

只有显式传入 `-SkipTests` 才跳过两套测试集，语法检查与 exe 冒烟验收始终执行。冒烟超时默认 120 秒，可用 `-SmokeTimeoutSeconds 180` 调整。日志保存在对应冒烟工程的 `电缆统计_自检.log`；暂存程序、历史备份和验收工程保留供排查。

也可用 PowerShell 指定项目运行：

```powershell
.\运行自动统计.ps1 -Project "<项目文件夹>"
```

脚本在项目文件夹里查找表头包含 `电缆编号`、`起点`、`终点`、`电缆长度` 的 Excel 工作簿（表头空格换行自动忽略，`自动统计`、`向上取整` 列缺失会自动补建），优先使用 `自动统计.xlsx`；找到多个符合的会报错提示改名。

## 输入数据

输入 CSV 放在项目文件夹的 `data/`：

- `参数.csv`：竖井高度、修正量、CAD 单位比例、吸附容差等参数
- `柜子坐标.csv`：柜子名称、楼层、坐标（兼容旧名 cabinets.csv）
- `路径线段.csv`：固定电缆沟或桥架路径线段（兼容旧名 route_segments.csv）
- `竖井.csv`：电缆竖井坐标和高度（兼容旧名 shafts.csv）
- `房间范围.csv`：按房间名称、楼层和多边形顶点导出的房间边界（可选）
- `柜名别名.csv`：清册名称 → CAD 名称映射，柜名对不上时人工维护
- `强制规则.csv`：按起点+终点强制指定修正量，覆盖自动判断

CAD 侧推荐加载 `cad_cable_wizard.lsp`，执行 `DDFD_CABLE_WIZARD` 按提示一步步建图层、定义房间、标柜子、画路径、标竖井，最后自动导出并复制进项目 `data\`；也可单独执行 `DDFD_CABLE_ROOMS` 定义房间。只想导出时执行 `DDFD_EXPORT_CABLE_ROUTE`。

## 输出结果

结果写入项目文件夹的 `outputs/`，不会覆盖原始工作簿：

- `自动统计_计算结果.xlsx`：写入自动统计值，并附带统计明细、柜子清单、参数和问题清单；该文件在 Excel 里开着时会另存为 `自动统计_计算结果_时分秒.xlsx`
- `统计明细.csv`：每条电缆的长度、规则、差值、状态和路径说明（`电缆长度` 是公式时按 Excel 上次保存的计算值算差值）
- `柜子清单.csv`：清册中出现的柜子、坐标提供状态，缺坐标时附近似 CAD 柜名建议
- `路径可视化.html`：本地交互页面，双击打开即可查看路径
- `路径可视化数据.json`：HTML 页面使用的结构化路径数据

路径可视化顶部的“检查线路”可选择疑似断点，自动切换楼层并显示检查点周围的线路（默认至少约 12 米范围）。地图上方提供「缩小 / 放大」「看全层」「回到检查点 · 看周边」「放大空隙 · 看细节」，也支持滚轮缩放；不再把缩小范围限制在小空隙附近。平面与三维均用编号红圈和红色虚线标出未连接的两端，红圈缩放后仍保持可辨认大小；右侧显示间隙（厘米/米）、附近柜名和处理建议，可点“上一处 / 下一处”逐个检查。也可在“问题清单”点击“在图上查看”。切换平面/三维保留当前检查点与说明，三维支持点击红圈、跨楼层逐处检查；窄窗口的说明显示在图下方，不遮挡地图。默认隐藏检查点；勾选顶部「检查点」可显示全部标记，取消勾选或点击「隐藏检查点，返回路径」会隐藏红圈/虚线并退出检查，恢复之前的楼层和电缆路径。再次点击「在图上查看」会自动显示并定位，平面和三维同步。隐藏仅影响画面，问题清单仍保留。这些标记只用于检查，不会自动接线或修改计算结果。更新软件后须重新计算工程并重新打开生成的 HTML，旧页面不会自动更新。

## 路径复核

打开 `outputs\路径可视化.html` 后，可在左侧搜索或筛选电缆，中间查看固定路径网和当前电缆高亮路径，右侧查看基础路径长度、修正量、自动统计值、规则和每一步路径来源。

页面顶部可切换「平面 / 三维」视图。三维视图把各楼层平面按竖井坐标对齐后上下叠放，竖井显示为楼层间的立柱，勾选「全部电缆」可一次看到所有电缆走向（重叠越多颜色越深）。鼠标操作与 CAD 一致：中键拖动平移，Shift+中键围绕鼠标下方的柜子、竖井或路径点旋转（旋转支点钉在原地不跳视角；左键旋转、右键平移同样可用），滚轮缩放、双击复位，点击某条电缆线可直接选中查看详情，「层间距」滑块可调节楼层间的视觉距离；平面视图也支持中键拖动平移、滚轮缩放、双击恢复自适应。

第一次上手先看 `快速上手（最简版）.md`（九步照做即可）；详细 CAD 图层约定、参数说明和常见问题见 `使用说明.md`。


## 房间识别规则（2026-09-23）

- **只有用向导“定义房间”（`DDFD_CABLE_ROOMS` 或菜单 R）写过名称的多段线才算房间。** `CABLE_ROOM_nF` 图层上没有名称的多段线（误放的图框、表格等）一律不导出，导出时命令行会提示有几个。
- 导出不再询问范围，直接扫描模型空间里的命名房间，并在命令行按楼层列出（如 `1F 10`、`2F 2DR`），数量不对当场就能看出来；同层重名也会提示。旧版的 `data\房间导出范围.txt` 已不再使用，下次导出时自动删除。
- `DDFD_ROOM_CHECK`（向导菜单 C）：选中并缩放到房间图层上未命名、或已命名但不闭合/含圆弧/图层看不出楼层的多段线，只选中不修改。确认是图框/表格后在特性里改回原图层或删除；也可用 `DDFD_CLEAN_ROOM_LAYERS` 把未命名的统一移到 0 层（先列出句柄并确认，输入 `U` 可撤销）。
- 定义房间不再切换当前图层，之后画的图形不会误落到房间图层；选中已定义的房间可直接改名，同层重名会先询问是否替换旧的。
- 计算端兜底：房间里既没有柜子也没有路径经过、或房间没有名称时，在结果工作簿“问题清单”和运行日志里提示。

向导先确认项目，再直接写入该项目 data 目录。四份 CSV 先生成临时文件，再成组替换；任一图元读取失败会报出句柄并放弃本次导出，不覆盖原数据。若提示 `.previous` 文件，请检查上次失败的备份，不要直接删除。

插件加载时会打印版本号（如 `版本 2026-09-23`）。更新插件后需在 CAD 重新加载项目目录中的 `cad_cable_wizard.lsp`，看到新版本号才算生效。
