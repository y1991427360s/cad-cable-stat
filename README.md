# 电缆长度自动统计工具

本工具用于根据 CAD 导出的柜子坐标、固定走线路径和电缆竖井信息，自动计算 `自动统计.xlsx` 中每条电缆的路径长度，并生成可视化页面帮助复核路径。

## 工具 + 项目结构

本文件夹是**通用工具**，不放任何项目数据。每个工程项目一个独立文件夹，清册、CAD 数据、结果都在项目文件夹里：

```text
本文件夹（通用工具）
├─ calculate_cable_lengths.py / run_auto_stat.py   计算脚本
├─ cad_cable_wizard.lsp                            CAD分步引导向导（推荐）
├─ cad_export_cable_route.lsp                      CAD仅导出命令
├─ 新建项目.cmd                                     双击创建新项目文件夹
├─ 项目模板\                                        新项目的骨架（也可直接复制改名）
└─ 项目\
   └─ <项目名>\                                     一个项目 = 一个文件夹
      ├─ 自动统计.xlsx                              清册
      ├─ data\                                      CAD导出数据 + 参数 + 别名
      ├─ outputs\                                   结果全在这里
      └─ 一键启动.cmd                               双击运行本项目
```

## 快速运行

### CAD 文字快速校核（HDDL）

在 CAD 中加载 `E:\366256\2027-AutoCAD-lisp\AA整合版本.lsp`，选中准备交给 `YSDL` 的文字后输入 `HDDL`。`HDDL` 已经完全内置在这个整合文件中，不依赖外部 LSP 或其他平台函数。命令按 YSDL 的行分组规则读取第二列电缆编号：同编号且起终点互换的合法镜像行不会误报；同向重复、超过两行或镜像两端原理号数量不一致时，整行改为红色并在行首生成 `[编号重复]` 或 `[原理号不一致]`。同一行第 5 列起的原理号/芯线号出现重复时生成 `[原理号重复]`。这样无需先导出 CSV、复制到项目或打开网页即可在原图上定位结构性错误。修正文字后重新选择并执行 HDDL，未被标记的行保持原有颜色。

行首标记统一放在 `HDDL_MARK` 图层；再次执行命令时只清理该专用图层中的旧标记，不会删除用户其他文字。

**双击 `电缆统计.exe` 就是完整软件**（图形界面，不需要装 Python）：

1. 点「新建项目」选位置、输名称，自动建好项目文件夹并打开；
2. 把清册 Excel 放进项目文件夹；点「导出CAD插件」把 lsp 给 CAD，跑 `DDFD_CABLE_WIZARD` 把 CSV 导入项目 `data\`；
3. 点「开始计算」，日志直接显示在窗口里；「打开计算结果」「打开路径可视化」一键查看，结果都在该项目的 `outputs\`。

每个项目文件夹里还有一个 `一键启动.cmd`：双击它会打开软件并**自动对这个项目开算**，习惯二选一。

exe 内嵌了计算引擎、项目模板和完整向导插件 `cad_cable_wizard.lsp`；根目录的 `cad_export_cable_route.lsp` 是仅供开发兼容的精简导出版，用户无需导出或加载。`.py` 源码留作开发和排查用（源码方式需要 `python -m pip install openpyxl`）。

改了 Python 源码后重新打包 exe：

```powershell
python -m pip install pyinstaller
$root = (Resolve-Path .).Path
python -m PyInstaller --onefile --noconsole --name 电缆统计 --icon "$root\app_icon.ico" --distpath "$root" --workpath "$root\_build" --specpath "$root\_build" --clean --add-data "$root\app_icon.ico;." --add-data "$root\cad_cable_wizard.lsp;." --add-data "$root\项目模板;项目模板" "$root\cable_stat_app.py"
# 打包完删除 _build 临时目录；验证：项目文件夹里 CABLE_STAT_SMOKETEST=1 运行 exe 看 电缆统计_自检.log
```

也可用 PowerShell 指定项目运行：

```powershell
.\运行自动统计.ps1 -Project "<项目文件夹>"
```

脚本在项目文件夹里查找表头包含 `起点`、`终点`、`电缆长度` 的 Excel 工作簿（表头空格换行自动忽略，`自动统计`、`向上取整` 列缺失会自动补建），优先使用 `自动统计.xlsx`；找到多个符合的会报错提示改名。

## 输入数据

输入 CSV 放在项目文件夹的 `data/`：

- `参数.csv`：竖井高度、修正量、CAD 单位比例、吸附容差等参数
- `柜子坐标.csv`：柜子名称、楼层、坐标（兼容旧名 cabinets.csv）
- `路径线段.csv`：固定电缆沟或桥架路径线段（兼容旧名 route_segments.csv）
- `竖井.csv`：电缆竖井坐标和高度（兼容旧名 shafts.csv）
- `房间范围.csv`：按房间名称、楼层和多边形顶点导出的房间边界（可选）
- `柜名别名.csv`：清册名称 → CAD 名称映射，柜名对不上时人工维护
- `强制规则.csv`：按起点+终点强制指定修正量，覆盖自动判断

CAD 侧推荐加载 `cad_cable_wizard.lsp`，执行 `DDFD_CABLE_WIZARD` 按提示一步步建图层、定义房间、标柜子、画路径、标竖井，最后自动导出并复制进项目 `data\`；也可单独执行 `DDFD_CABLE_ROOMS` 定义房间。只想导出时执行 `DDFD_EXPORT_CABLE_ROUTE`。

## 输出结果

结果写入项目文件夹的 `outputs/`，不会覆盖原始工作簿：

- `自动统计_计算结果.xlsx`：写入自动统计值，并附带统计明细、柜子清单、参数和问题清单
- `统计明细.csv`：每条电缆的长度、规则、差值、状态和路径说明
- `柜子清单.csv`：清册中出现的柜子、坐标提供状态，缺坐标时附近似 CAD 柜名建议
- `路径可视化.html`：本地交互页面，双击打开即可查看路径
- `路径可视化数据.json`：HTML 页面使用的结构化路径数据

## 路径复核

打开 `outputs\路径可视化.html` 后，可在左侧搜索或筛选电缆，中间查看固定路径网和当前电缆高亮路径，右侧查看基础路径长度、修正量、自动统计值、规则和每一步路径来源。

页面顶部可切换「平面 / 三维」视图。三维视图把各楼层平面按竖井坐标对齐后上下叠放，竖井显示为楼层间的立柱，勾选「全部电缆」可一次看到所有电缆走向（重叠越多颜色越深）。鼠标操作与 CAD 一致：中键拖动平移，Shift+中键围绕鼠标下方的柜子、竖井或路径点旋转（旋转支点钉在原地不跳视角；左键旋转、右键平移同样可用），滚轮缩放、双击复位，点击某条电缆线可直接选中查看详情，「层间距」滑块可调节楼层间的视觉距离；平面视图也支持中键拖动平移、滚轮缩放、双击恢复自适应。

第一次上手先看 `快速上手（最简版）.md`（九步照做即可）；详细 CAD 图层约定、参数说明和常见问题见 `使用说明.md`。


## 房间导出范围（2026-09-20 修复）

导出时首次默认选择房间，请框选当前工程各楼层所需的房间边界；直接回车不再全图导出。成功后在项目 `data/房间导出范围.txt` 保存图纸路径和房间句柄，下次默认复用。换图纸、房间被删除或边界失效时必须重新选择；增加房间后选 S 更新范围。选 A 全图导出需再输入 Y 确认，选 N 表示本次明确不使用房间并清空房间 CSV。

向导先确认项目，再直接写入该项目 data 目录，不再从公共 cable_export 目录复制旧数据。取消选择不覆盖 CSV，也不启动统计。四份 CSV 先生成临时文件，再成组替换；替换失败时恢复备份。若提示 `.previous` 文件，请检查上次失败的备份，不要直接删除。

更新插件后需在 CAD 重新加载项目目录中的 `cad_cable_wizard.lsp` 才会生效。程序不会删除 CAD 中的旧房间实体，也不会按距离猜测并删除有效房间。
