# 电气二次设计工作台

面向电力设计、变电站二次设计的 Windows 桌面辅助工具。V1 在同一个 tkinter/ttk 主窗口中提供电缆长度统计、柜名匹配、CAD 路径数据导出与可视化复核，以及端子排输入检查、接线解析和 DXF 自动出图。成果与业务数据都属于当前工程，工程文件夹可以直接复制、备份。

**日常使用只需双击 `电气二次设计工作台.exe`，不需要安装 Python 或启动其他软件进程。** CAD 用于导出原图数据及打开 DXF，Excel 用于编辑、查看清册；生成成果本身不依赖 CAD 或 Excel 进程。V1 保留两项目已验证的电缆计算及端子绘图算法，没有引入数据库、网页服务或云服务。

## 快速开始

1. 启动工作台，点「新建工程」选择位置和工程名称，或者「打开工程」进入已有工程。原电缆工程可以直接打开，无需迁移。
2. **电缆统计**：将清册 Excel 放进工程根目录；从 CAD 导出柜子、路径和竖井数据到 `data\`。检查计算参数、柜名映射，再点「计算电缆」。
3. **路径复核**：打开 `outputs\路径可视化.html`，查看平面、三维路径和检查点；结果工作簿与问题清单一起用于核对。
4. **端子出图**：进入「端子排出图」页面，粘贴端子排和接线，填写柜名、设置默认及各端子排方向。按 `F5` 检查，按 `Ctrl+Enter` 生成完整图和仅接线图。
5. 在「问题清单」查看电缆、端子问题的来源与级别，在「输出文件」打开成果或所在文件夹。

端子页面激活时，`F5` 检查端子输入，`Ctrl+Enter` 生成 DXF；其他页面继续使用电缆刷新、计算快捷键。`Ctrl+O` 打开工程。端子出图在后台执行，运行期间不能重复生成或切换工程；完成结果由主线程更新界面。

端子输入会在成功生成、切换工程前和关闭程序前保存。两个 TXT 和一个 JSON 成组保存；文件替换失败时恢复已替换的输入。若恢复也失败，提示会给出原件备份路径；请保留对应的 `.save-backup-*.bak` 文件并按提示恢复，切换工程或关闭前先解决保存问题。电缆参数和柜名映射分别用「保存参数」「保存映射」保存；有未保存修改时按提示选择保存、放弃或取消操作。工程启动器 `一键启动.cmd` 会打开本工程；找到有效电缆清册时自动计算，只含端子数据时只打开工程。

## 工程与软件结构

通用工具代码和工程数据分开。软件根目录默认的 `项目\` 可以存放多个工程，也可以把工程放在其他位置。

```text
电气二次设计工作台/
├─ 电气二次设计工作台.exe           唯一正式桌面程序
├─ app.py                           统一源码/打包入口
├─ cable_stat_app.py                工程、配置、单实例、计算与自检入口
├─ cable_stat_gui.py                唯一主窗口及电缆页面
├─ cable_stat/                      原电缆计算引擎、HTML 模板
├─ modules/terminal/
│  ├─ duanzi_dxf_tool.py             原端子解析、布局、DXF 核心
│  ├─ service.py                    工程存储与端子功能适配
│  └─ page.py                       嵌入式端子页面
├─ core/models.py                   统一问题与未来业务实体接口
├─ ui/workbench_pages.py            工作台导航、问题及成果页面
├─ tools/workbench_smoke.py         电缆/端子联合冒烟验收
├─ build_exe.ps1                    检查、打包、验收、备份、发布
├─ 项目模板/                       新工程骨架
└─ 项目/<工程名>/
   ├─ 自动统计.xlsx                 原始清册（不会覆盖）
   ├─ data/
   │  ├─ 参数.csv
   │  ├─ 柜子坐标.csv
   │  ├─ 路径线段.csv
   │  ├─ 竖井.csv
   │  ├─ 房间范围.csv               可选
   │  ├─ 柜名别名.csv
   │  ├─ 强制规则.csv
   │  └─ terminal/
   │     ├─ 端子排.txt
   │     ├─ 接线.txt
   │     └─ settings.json
   ├─ outputs/
   │  ├─ 自动统计_计算结果.xlsx
   │  ├─ 统计明细.csv
   │  ├─ 柜子清单.csv
   │  ├─ 路径可视化.html
   │  ├─ 路径可视化数据.json
   │  └─ 端子排/
   │     ├─ 柜名-端子排.dxf
   │     └─ 柜名-端子排-仅接线.dxf
   └─ 一键启动.cmd
```

旧工程没有 `data/terminal/` 也能打开，打开工程时自动创建该目录，首次保存端子数据时写入两个 TXT 和一个 JSON。端子文本、柜名、方向均按工程独立保存，不使用旧端子软件的全局 `state.json` 作为业务存储。全局配置位于 `%APPDATA%\电气二次设计工作台\`，只保存最近工程、窗口状态等应用设置。

## 电缆模块

清册优先使用符合表头要求的 `自动统计.xlsx`；没有该文件时，工程中须只有一份符合条件的源清册，也可使用其他文件名。表头必须包含 `电缆编号`、`起点`、`终点`、`电缆长度`，表头内的空格、换行会自动忽略。缺少 `自动统计`、`向上取整` 列时，在结果工作簿中补建。原始清册始终保留。

`data/` 输入如下，中文 CSV 均采用带 BOM 的 UTF-8：

| 文件 | 用途 |
| --- | --- |
| `参数.csv` | CAD 单位比例、吸附容差、竖井高度和长度修正参数 |
| `柜子坐标.csv` | CAD 柜名、楼层、坐标，兼容旧名 `cabinets.csv` |
| `路径线段.csv` | 电缆沟、桥架固定路径，兼容旧名 `route_segments.csv` |
| `竖井.csv` | 跨楼层竖井及高度，兼容旧名 `shafts.csv` |
| `房间范围.csv` | 有名称的闭合多段线房间边界，可选 |
| `柜名别名.csv` | 清册名称到 CAD 名称的人工映射 |
| `强制规则.csv` | 按起点、终点覆盖自动修正规则 |

模板按毫米图配置：`CAD每米单位=1000`、`吸附容差=0.05`、`最大接入距离=20000`。米图、厘米图应根据实际 CAD 单位修改。柜名匹配页的相似名称是建议，需要人工核对后保存映射。

结果工作簿包含统计明细、柜子清单、参数和问题清单；文件被 Excel 占用时另存时间戳版本。差值使用源清册上次保存的公式计算值。路径复核页面支持电缆搜索、平面/三维切换、楼层切换、中键平移、滚轮缩放和疑似断点定位。检查点用于复核，不会自动连接断点或修改计算结果。更新程序后重新计算，再打开新生成的 HTML。

源码批处理入口保持兼容：

```powershell
.\运行自动统计.ps1 -Project "<工程文件夹>"
python .\calculate_cable_lengths.py --workbook "<工程文件夹>\自动统计.xlsx" --data-dir "<工程文件夹>\data" --output "<工程文件夹>\outputs\自动统计_计算结果.xlsx"
```

## 端子模块

端子排输入支持普通格式和 CAD 坐标格式，两种格式不能混在同一段输入中。文本导入兼容 UTF-8、GBK、UTF-16；输入框保留行号、撤销、右键编辑和示例填入。

普通格式每行一块，第一项是名称：

```text
ZD、1、11
X、1、2、3
```

坐标格式每行 `横坐标,纵坐标 文字`，名称行必须以 `端子名` 结尾：

```text
-2435.48,992.73 X 端子名
-2297.36,992.73 X2 端子名
-2435.48,987.73 1
-2297.36,987.73 51
```

坐标格式按原算法识别纵列或横排；没有名称归属的文字会报错。坐标中的重复端子号保留各格，接线接第一次出现的位置并提示；普通格式重复端子号会报错。同名普通端子段可以合并，`QD-COM`、`X/X2` 及以 `D` 结尾的名称继续兼容。

接线每行 `端子引用、原理号、去向柜`；同一根电缆只在最后一条填去向柜，接线留空时仅画端子排：

```text
X:1、A610
X:2、B903、甲柜
X:3、701、乙柜
```

`ZD2`、`ZD:2`、`ZD：2` 等价；`QD:COM1`、`QD：COM1`、`QD-COM1` 均可引用 `QD-COM` 的 1 号。显式冒号按名称和编号严格拆分；没有冒号且有歧义（例如 `X21`）时沿用最长名称匹配，并提醒补冒号。连续接线、连字符及多电缆规则保持原核心行为。

柜名决定图签与文件名，方向表可为各块端子排分别选择向上、向下。成果固定写入当前工程 `outputs/端子排/`；文件被 CAD 占用时自动改用时间戳名称。完整图锁定端子排框线、名称、编号、图签，接线相关图层保持可编辑。仅接线图的接线坐标和完整图一致，可直接全选复制。

### 固定出图规则

- 端子格节距 5 mm，端子排总高 75 mm；默认电缆方向向下。
- 每行电缆距离从 10 mm 开始，按 15、20、25…递增。
- 同端子多电缆引线以 1 mm 间距在中心两侧平均分配；左侧引线对应较近电缆。
- 向上引线保留 `SJ` 短线，向下引线保留 `XJ` 短线。
- 原理号 ACI 4、水平电缆线 ACI 3，其余对象 ACI 7。
- 文字样式 `HZ`，常规字高 3、宽度因子 0.7；图签等文字以原绘图实现为准。
- `BIAN` 标注基准：电缆右端左侧 40 mm 为方向三角尖点，编号在尖点左 20 mm，`至` 在右 1.5 mm，规格在右 32 mm。
- 图形保留原有可编辑 `LINE`、`TEXT` 等实体与锁层规则；以原核心测试及实际出图行为为准。

锁层能保护背景修改，但不同 CAD 的选择、复制行为可能不同。只复制接线时使用独立的 `-仅接线.dxf`。

## CAD 插件

在工作台「数据导出」页面点「导出 CAD 向导…」，把完整向导 `cad_cable_wizard.lsp` 保存到工程文件夹。在 CAD 中 `APPLOAD` 加载，执行 `DDFD_CABLE_WIZARD`，按菜单定义房间、柜子、路径和竖井；第 5 步确认工程文件夹后，直接导出到该工程 `data\`。用户只需加载这一份插件，根目录的 `cad_export_cable_route.lsp` 保留为开发兼容源码。

仅有通过 `DDFD_CABLE_ROOMS` 写入名称的闭合直线多段线才算房间。未命名的图框、表格不会被当成房间；`DDFD_ROOM_CHECK` 可选中待检查图元。定义房间不会修改当前图层。导出遍历 DXF 顶点，先写临时文件，再成组替换；实体读取失败不会覆盖原数据。

修改 LISP 后必须重新打包、导出并在 CAD 重新加载，核对加载时显示的版本。两份 LISP 的导出逻辑应同步，并按 GBK + CRLF 保存。CAD 详细说明见 `使用说明.md`，电缆九步入门见 `快速上手（最简版）.md`。

## 模块接口与后续扩展

主窗口只创建一个 `tk.Tk`。端子页面是 `ttk.Frame`，调用 `TerminalService`，不再启动旧端子 GUI 或第二个 EXE。原端子核心迁入 `modules/terminal/duanzi_dxf_tool.py`；解析、布局、绘图维持原行为，适配层负责工程路径、状态和问题转换。

`TerminalService(project).inspect(payload)` 检查输入，`generate(payload)` 返回 `ok`、`path`、`wiringPath`、错误及警告等结果。界面不承担 DXF 业务算法。统一问题按来源、级别、内容展示，保留两模块自己的诊断过程。

`core/models.py` 为 Project、Cabinet、Cable、TerminalStrip、Terminal、Connection、CableCore 等实体预留接口。V1 继续使用 Excel/CSV/TXT/JSON/DXF，不要求旧数据立即迁移。

## 开发、测试与构建

已验证开发环境为 Windows、Python 3.14、openpyxl 3.1.5、ezdxf 1.4.3、PyInstaller 6.21.0。依赖版本记录在 `requirements.txt`：

```powershell
python -m pip install -r .\requirements.txt
python .\app.py

# 电缆原基线使用独立入口，不能仅靠 unittest discovery 代替。
python -m test_calculate_cable_lengths
# 原电缆回归、原端子核心、端子页面和工程集成测试。
python -m unittest discover -v
```

正式构建命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_exe.ps1
# 或指定已安装的 Python：
.\build_exe.ps1 -Python "C:\Python314\python.exe"
```

构建脚本不会安装或升级依赖。依次执行语法检查、导入检查、电缆独立基线、全部 unittest，再生成 **单文件、无控制台** EXE。图标沿用母项目；完整 CAD 向导、项目模板、HTML 模板以及 ezdxf/openpyxl 的运行资源都被内嵌。

暂存输出为 `_build_release\dist\电气二次设计工作台.exe`。发布前在独立 `_build_release\smoke_<时间>\` 工程中用 `CABLE_STAT_SMOKETEST=1` 启动这个 EXE，自动验证：

- 原电缆直线、拐弯长度和柜名别名，Excel、CSV、HTML、JSON 输出及原始清册哈希。
- 同一工程下的端子输入、完整 DXF 和仅接线 DXF，文件非空、ezdxf 回读、实体、HZ 样式、锁层以及两图接线坐标一致。
- 内嵌图标、LISP、项目模板及 HTML 模板与当前源码逐字节一致。

只有全部通过才备份原正式版到 `_build_release\backups\`，然后原子替换根目录 `电气二次设计工作台.exe`。失败保留原正式版和验收文件。`-SkipTests` 只跳过测试集，不跳过语法、导入和 EXE 冒烟；`-SmokeTimeoutSeconds 180` 可调整默认 120 秒超时。

为兼容既有验收脚本，自检环境变量与日志名仍使用 `CABLE_STAT_SMOKETEST` 和 `电缆统计_自检.log`；端子回读报告位于验收工程的 `outputs\端子排\smoke_validation.json`。普通生成不会写这个验收报告。端子自检使用唯一验收柜名，完成或异常退出时均恢复工程内三个端子输入文件的原字节，原来不存在的文件不会留下测试内容。不要把工程数据、EXE、临时 Office/CAD 文件或构建目录提交到源码仓库。
